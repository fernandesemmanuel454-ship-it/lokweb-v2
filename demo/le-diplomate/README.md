# Démo privée — Le Diplomate Dudelange

Maquette commerciale bilingue français-portugais. Elle n'est pas le site officiel du restaurant et ne transmet aucune réservation.

## Parcours de démonstration

- Direction visuelle claire et chaleureuse inspirée des couleurs luso-brésiliennes.
- Chaque plat représentatif possède un bouton d'ajout ouvrant un exemple d'upsell.
- L'upsell suggère une boisson ou un accompagnement sans inventer de produit ni de prix.
- Aucun paiement n'est encaissé : la suite du parcours renvoie vers Wolt, Uber Eats ou Wedely.
